# Count Down Web App
visit : https://count-down-five-flax.vercel.app/
A modern, beautiful countdown timer web application built with React and Vite.

## Features

- 🎉 **Preset Events**: Quick access to upcoming celebrations (New Year, Ramadan, Eid, Pohela Boishakh)
- ✨ **Custom Countdowns**: Create personalized countdowns for any special moment
- 🎨 **Multiple Themes**: Choose from beautiful gradient themes or use custom background images
- 🌓 **Dark/Light Mode**: Seamless theme switching
- 📱 **Responsive Design**: Works perfectly on all devices
- 🔗 **Shareable Links**: Share your countdowns with friends via URL
- 🎊 **Celebration Effects**: Confetti animation when countdown reaches zero
- 💎 **Glassmorphism UI**: Modern, premium design with glass effects

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:3000`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
